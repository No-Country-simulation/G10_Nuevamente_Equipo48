# Entregables — Corpus NuevaMente

Este paquete contiene:

1. Especificación del corpus.
2. Esquema de metadatos.
3. Criterios de aceptación de documentos.
4. Plantilla de inventario del corpus.
5. Ejemplo de metadatos de un documento.

El propósito es entregar al equipo una estructura común para que pueda trabajar mientras continúa la selección de los documentos definitivos.

## Nota sobre términos técnicos

Se conservan únicamente las denominaciones técnicas que corresponden al proyecto, como PDF, Markdown, TXT y RAG. Los nombres de campos, estados y criterios están expresados en español para facilitar su uso por todo el equipo.
