# NuevaMente — Criterios de Aceptación de Documentos

| Criterio | Pregunta de control | Requisito |
|---|---|---|
| Documento completo | ¿Tenemos el documento completo? | Obligatorio |
| Formato | ¿Es PDF, Markdown o TXT? | Obligatorio |
| Fuente | ¿Está identificada la fuente? | Obligatorio |
| Pertinencia | ¿Corresponde al dominio seleccionado? | Obligatorio |
| Profundidad | ¿Contiene información suficiente para adaptación? | Obligatorio |
| Procedencia | ¿Podemos identificar de dónde proviene? | Obligatorio |
| Integridad | ¿Está completo, legible y utilizable? | Obligatorio |
| Trazabilidad | ¿Podemos relacionarlo con su fuente? | Obligatorio |

## Criterios para comparar candidatos
- Calidad de la fuente.
- Actualidad y versión.
- Riqueza temática.
- Claridad del contenido.
- Capacidad de adaptación.
- Utilidad para los casos de uso definidos por el equipo.

## Regla de decisión
Un documento no pasa a APROBADO si falla alguno de los criterios obligatorios.
